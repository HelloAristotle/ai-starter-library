# Use it again in a fresh chat

The useful test is a new example. Keep the method, provide the current facts, and check the result yourself.

## If you saved a context note

Start a new chat. Paste or attach the note, or give its location to an AI that can read that folder. Then send:

```text
Use the context note I supplied for this task. First name the file or pasted
note you actually read and give two facts that matter here. If you cannot
read it, tell me and ask me to paste it. Do not invent what it says.

Ask what small result I want next, unless I already told you. Use only the
relevant current facts, ask about important gaps, and make a first version.
Afterward, show me what I should check. Do not assume old dates, prices, or
availability are still current.
```

Compare those two facts with the note yourself. Then try something new, such as a reply to a different question. Repeating the original example word for word does not show the method works on new input.

## If you saved a method

Paste or attach the method as well. You can say:

```text
Use the method I supplied on this new example. Follow its process while
using the current facts I give you now. Ask one important question at a time
if needed. Keep any missing facts clear and return one useful result I can
check. Do not reuse details from the old practice example as facts about
this one.
```

These files are plain instructions. You can use them by explicit reading without installing a tool-specific skill.

## If the first answer disappoints you

```text
This result needs work. Help me diagnose it before rewriting everything. Ask
what is wrong: the facts, missing background, the direction, or the way it
is written. Use what I already told you. Ask for the one missing detail that
would change the result most, then give me one improved version. Explain the
important fix in one sentence. Do not fill gaps with invented facts.
```

Useful feedback is concrete: "The reader is a first-time customer," "We haven't agreed on a date," or "I want a friendly answer, not a sales pitch."

## If a fact has changed

```text
Help me update my saved context with a confirmed change. Ask for the change
and the current note if I have not supplied them. Identify where that fact
already lives. Show the proposed revision and any conflict. Keep one current
copy, preserve unrelated content, and label unresolved facts. Save only if I
ask you to, then read back the changed note and tell me its location.
```

Keep temporary case details with that case. A one-time deadline does not belong in a permanent writing method.

## Your finish check

You can find the note, correct it, and use it on a new task. You understand what the AI actually read. The output uses the right facts and leaves unknowns open. If something fails, fix that specific part before making the system bigger.
