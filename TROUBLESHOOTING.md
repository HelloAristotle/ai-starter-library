# If something isn't working

Use the row that matches what happened. Fix that one step, then continue.

| What happened | What to do next |
|---|---|
| "I can't open GitHub." | Paste the text of README.md and SETUP.md. Add the selected method/template when needed. You can also download the ZIP and attach those files if supported. |
| "I can see the link, so I'm ready." | Ask which file it actually read and one instruction from it. A visible URL is not proof of access. |
| "I can't save files." | Ask for the complete note, then save it yourself in a private document. Paste it next time. |
| "I can't find that folder." | Confirm which folder the app has access to. Select only the intended workspace through the app's normal controls, or use pasted text. |
| The AI keeps asking questions. | Say: "Use what you have to make the smallest useful first version. Ask only if a missing fact makes that impossible." |
| The result is generic. | Give one real example, the intended reader, or the actual question it needs to answer. See the repair prompt in USE-AGAIN.md. |
| It invented a date or promise. | Point to the unsupported claim and ask it to remove it or mark it unknown. Check the revised version against the source. |
| It wants to automate something huge. | Ask for one draft or checklist you can check today. Add connected tools only when a real task needs them. |
| It says it will remember forever. | Save a checked note and test a fresh chat. Ask it to identify the source it actually read. |
| I already have context or instruction files. | Ask it to inspect the relevant existing files and propose the smallest change. Preserve the current source and unrelated content. |
| It wants me to run commands or install things. | This library's first exercise only needs text. Ask to use the paste/attach route. Follow official app setup guidance only if you choose to install the app. |
| I don't know a requested fact. | Say "I don't know." The AI should narrow the task, leave the fact open, or offer a clearly fictional practice exercise. |

## A prompt to get back on track

```text
Let's make this simpler. Tell me the smallest useful result we can make with
the information and tools actually available. Use what I already told you.
Ask one question only if it is necessary, then help me finish and check that
result. Explain any unavailable tool plainly and offer a copy-and-paste
alternative.
```

## Where your information belongs

Keep filled-in context in your own suitable private document or workspace, separate from this public library. Do not put real customer notes, resumes, passwords, or private company documents in GitHub issues or a public fork. When asking a public question, describe the problem with a made-up example.

If an app feature is unavailable for your account, the text prompts remain usable in a chat you can access. This library does not change product permissions or subscription requirements.
