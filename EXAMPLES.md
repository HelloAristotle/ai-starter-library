# Fictional example: one follow-up, ready to review
All names and details on this page are invented for practice. These are not client facts or approved commitments.

## Input
Task: draft a short follow-up to a prospective customer after a website review call. Use METHOD-MEETING-ACTIONS.md, then METHOD-WRITE.md if editing helps.

Notes supplied by the owner: “At our 22 September 2026 call, Lee said the quote request page is confusing. I agreed to send two layout ideas. Lee will send the current form text. No deadline was agreed. We discussed possibly reviewing the mobile page later; no work was booked.”

## Checked draft
Subject: Next steps for the quote request page

Hi Lee,

Thanks for walking me through the quote request page. I'll send two layout ideas, and you'll send the current form text so I can work from the right version.

We also discussed a possible mobile-page review. We can decide on that separately.

What timing would work for exchanging the form text and layout ideas?

## Why this is usable
The two agreed actions remain intact. The draft does not invent a deadline, booking, price, measured conversion gain or wider project. Before sending, the owner checks the recipient and that the stated commitments match the call. The draft has not been sent.

## Fresh practice
New notes: “Lee sent the text. The owner proposed sending one sketch on Thursday, but Lee did not agree to timing. Lee asked whether accessibility testing was included; scope is undecided.”

Use the same skill to draft the next reply. Check: received text can be acknowledged; Thursday is a proposal; accessibility is an open scope question; no completed testing or sale is invented. Compare against those checks before using the draft.

## Try it yourself

Open a fresh chat. Paste the prompt from [the meeting method](METHOD-MEETING-ACTIONS.md), then the input above. Compare the output with the checks, rather than expecting exactly the same wording.

The result should preserve both agreed actions, leave timing open, and keep the mobile review separate. If it promises Friday or says the work is booked, point to the sentence that went beyond the notes and ask for a correction. No email needs to be connected or sent.

## Save one useful piece, if you want

For this fictional exercise, a reusable preference might be: "Follow-up drafts should be brief, separate agreed actions from possible future work, and flag missing dates." Only save that as your actual preference if you choose it. Do not save Lee or the fictional business details as your real contacts or company facts.
