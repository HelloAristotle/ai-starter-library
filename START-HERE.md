# Start here, one small step at a time

You do not have to understand every file in this library. Start with one useful result, or one note you want your AI to understand.

## 1. Open the AI you already use

Start a new chat in an app you have access to. The text prompts can be pasted into an ordinary chat. Reading web links, opening local folders, and saving files depend on that particular app and your permissions.

If you want help choosing, tell the AI what app you have. You do not need a new subscription just to try a prompt in a chat you can already use.

## 2. Paste the setup prompt

Open [SETUP-PROMPT.txt](SETUP-PROMPT.txt), copy all the text, and send it to your AI. It already contains the library's GitHub URL. The same prompt is on the [main page](README.md).

The AI should read the library, or explain that it cannot. If it cannot open the link, you have two options:

- **Copy the text:** open [README.md](README.md) and [SETUP.md](SETUP.md) in GitHub. Copy the text into your chat and say, "These are the library instructions. Help me use them."
- **Attach the files:** on the repository's main page, choose **Code → Download ZIP**. Unzip the download. Attach README.md and SETUP.md if your app supports files. Add the chosen method or context template when the AI needs it.

Do not attach every document you own. Start with these instructions and one relevant example. [GitHub's own download guide](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives) shows how the ZIP download works.

## 3. Choose your first finish

You can answer in ordinary words. Here are three examples:

- "I want to reply to a customer without sounding stiff."
- "Help me make a note about my work so I stop repeating myself."
- "I'm not sure. I have some meeting notes and a messy to-do list."

The AI should offer a small step you can actually check. Turning one meeting into a short action list is a good start. Automating an entire business is something to break into smaller pieces.

You can say "skip," "I don't know," or change your mind. If you have already given an answer, the AI should use it. You should not have to complete a long questionnaire.

## 4. Give it the few facts that matter

For an email, that might be the reader, their question, and what you can honestly promise. For a context note, it might be what you do, who you help, and one preference.

Use a fictional example if you do not have a suitable real one. Ask the AI to keep practice details separate from your actual facts. The [example page](EXAMPLES.md) has one ready to try.

## 5. Check the result before adding more

Read the result yourself. Ask:

- Does this do the thing I asked for?
- Are the names, facts, dates, and promises right?
- What is still missing or uncertain?
- Would I actually use this?

Give one specific correction: "Make it shorter," "We never agreed to Friday," or "That sounds too formal." The AI should repair that issue and help you finish. You can stop with a useful draft.

## 6. Save only what will help next time

If a short context note or method would save you effort, keep it in a location you control. If you already have a good place for these facts, use it instead of making a second version.

**In an ordinary chat:** copy the complete note into a private document or notes app. Give it a clear title, such as "My work context." Paste or attach it in a new chat when needed.

**With a folder-capable AI:** choose a small private folder, such as "My AI Workspace," outside the downloaded public library. Tell the AI to use that folder and show you the proposed files before saving. Start with a short index and one context note. Open the saved files yourself. If your AI cannot access the folder, use the copy-and-paste route.

A possible result looks like this; your existing layout may be different:

```text
My AI Workspace/
  START-HERE.md          where the current notes are
  CONTEXT-RULES.md       how to use and correct them
  context/
    work.md             your checked work facts
```

Choose personal.md instead for personal use. Keep personal and company information separate when they have different audiences. Add an outputs folder or saved method only when useful. These are suggested filenames, not software you need to install.

## 7. Try a fresh chat

Open [USE-AGAIN.md](USE-AGAIN.md). Start a new chat, provide your saved note or its accessible location, and use the reuse prompt. Ask the AI to name the file it read and two relevant facts. Check those facts against your note. Then try a new small example.

If it cannot read the note, paste it. If it invents a fact, correct the source or narrow the task. A saved file is useful; it is not proof that every future chat will load it automatically.

## If you want to use local folders

Use the current official instructions for your app. We checked these links on October 13, 2026; buttons and plan availability can change.

**ChatGPT desktop / Codex:** the official quickstart covers installing and signing in, opening a folder, and choosing a chat mode. For local work, choose the intended folder in your app. A ChatGPT project with uploaded files and a local project with folder access are different; use the route your app actually offers. See [OpenAI's quickstart](https://learn.chatgpt.com/docs/quickstart) and [projects and chats](https://learn.chatgpt.com/docs/projects).

**Claude Code on desktop:** the official guide uses the Claude desktop app's **Code** tab, then **Local → Select folder**. The desktop path does not require a separate command-line installation. Check current plan requirements there. If the feature is unavailable, you can still use the text prompts in an ordinary chat you can access. See [Anthropic's desktop quickstart](https://code.claude.com/docs/en/desktop-quickstart).

Start with one ordinary file you are comfortable sharing with the selected tool. Keep its normal review controls. Do not give an AI access to your whole computer to make this exercise work.
